# Music Analysis Bot

Проект по разработке Telegram-бота для анализа аудио и рекомендации похожей музыки.

## Состав
- **Анализатор аудио** (Python) – извлечение акустических характеристик.
- **Telegram-бот** (Rust) – взаимодействие с пользователями.
- **Система рекомендаций** (Python) – поиск похожих треков.

## Запуск
Каждый микросервис запускается отдельно. Инструкции внутри соответствующих папок.
